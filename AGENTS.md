# OpenCode Agent Guidelines — Desktop Test Application

## Essential Commands

```bash
pip install -r requirements.txt
pip install reportlab  # Optional, for PDF export
python main.py         # Run the app
build_exe.bat          # Build single exe via PyInstaller
```

## Architecture

**Entry point:** `main.py` → `gui.py` (class `TestApp`, holds all shared state) → mode windows

**Mode windows** (all `tk.Toplevel` subclasses, receive data via constructor params, not globals):
- `mode_selection.py` — card-based mode selector (ModeSelectionWindow)
- `study_mode.py` — view regulation content (StudyModeWindow, uses PanedWindow with tree + text)
- `test_mode.py` — standard test (TestModeWindow, ~1432 lines — largest file)
- `scenario_test_mode.py` — scenario-based test (ScenarioTestModeWindow, ~1358 lines)
- `results_viewer.py` — history table with detail expand (ResultsViewerWindow)
- `question_bank_window.py` — import/select/delete question banks

**Supporting modules:**
- `_utils.py` — `get_base_path()` (data files, read-only) / `get_output_path()` (writable output). Handles both dev mode and `sys._MEIPASS` for PyInstaller bundle
- `style_config.py` — Colors, Fonts, Spacing classes (Material Design 3 inspired)
- `pdf_generator.py` — PDF export via reportlab
- `question_bank_manager.py` — manages bank files in `{output_path}/questions/`

**Data files (source of truth, UTF-8 JSON, never edit auto-generated ones):**
| File | Structure | Notes |
|---|---|---|
| `reglament.json` | `{document_title, version, last_updated, sections}` | 8 sections |
| `questions.json` | `[{id, type, question, options, correct_answer, ...}]` | 233 questions, IDs 1-240 (gaps exist). Types: `single_choice`, `multiple_choice`, `ordering`, `true_false` |
| `test_scenarios.json` | `{test_scenarios: [...]}` | 40 scenarios |

**Auto-generated (never edit manually, gitignored):**
- `user_data.json`, `test_results.json`, `results/*.pdf`, `questions/index.json`

## Build System

```bat
build_exe.bat
```
- Uses `.venv\Scripts\pyinstaller.exe` version 6.20.0
- `--onefile` with `app_icon.ico` as exe icon
- Bundles: questions.json, reglament.json, test_scenarios.json, app_icon.png, app_icon.ico, style_config.py, _utils.py, pdf_generator.py
- Output: `dist\tester 1.1.exe` (~20 MB)
- Run `--clean` each build (removes cache)
- Spec file: `tester.spec` (manual) or `tester 1.1.spec` (auto-generated by bat)

## Styling Conventions

- **Colors, fonts, spacing** → use `style_config` `Colors`, `Fonts`, `Spacing` classes everywhere
- Exception: `study_mode.py` hardcodes `#1A56C4`, `#F0F2F5`, `#154B8C` — match existing pattern if modifying that file specifically
- Button creation: prefer `create_button()` helper from `style_config`
- Header bars: prefer `create_header()` helper from `style_config`
- Cards: use `create_card()` helper for consistent bordered containers

## Data & Question Conventions

- Question IDs must be **sequential integers** (gaps allowed but no duplicates)
- Question types: exactly these four — `single_choice`, `multiple_choice`, `ordering`, `true_false`
- `test_scenarios.json` — array under `"test_scenarios"` key, each scenario references question IDs
- All JSON is UTF-8 encoded with `ensure_ascii=False` and `indent=2` when writing

## Important Gotchas

- `check_json.py`, `diagnose_json.py`, `fix_json.py` — no longer exist, do not reference them
- `launcher.py`, `run.bat` — no longer exist
- Old README says "601 questions" — wrong, actual count is 233
- No formal test suite — verify via manual execution in all modes
- Mode windows use `protocol("WM_DELETE_WINDOW", self.on_back)` to handle close
- `.gitignore` excludes: `__pycache__/`, `*.pyc`, `build/`, `*.spec`, `.venv/`, `user_data.json`, `test_results.json`, `results/`, `.idea/`
- When adding a new mode window, register it in `gui.py` with the same pattern (callback pair, load data, pass on constructor)
